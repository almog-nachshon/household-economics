# בית 2030

דשבורד אישי למעקב אחרי ההתקדמות לקניית בית.

## הרצה מקומית
```bash
cp .env.example .env
npm install
npx prisma db push
npm run seed   # נתוני דמה בלבד
npm run dev
```

## כניסה
```bash
npm run auth:setup -- "סיסמה של 12 תווים לפחות"
```
מעתיקים את שלוש השורות ל-`.env`, ואת `TOTP_SECRET` מוסיפים ל-Google Authenticator (הזנת מפתח ידנית).

## גילוי הזדמנויות השקעה

במסך **השקעות → גילוי הזדמנויות מרחבי השוק**, הורידו את ההנחיות ואת סכמת JSON 4.1. צרפו את הסכמה לשיחת ChatGPT עם חיפוש ברשת, הדביקו את ההנחיות וייבאו את קובץ התוצאות באותו מסך. הייבוא בודק את גרסת הסכמה, טווחי הערכים, חותמות הזמן והפניות למקורות. אימות תוכן המקורות מתבצע במחקר החיצוני. כל ייבוא ייחודי נשמר בהיסטוריה. דוחות 1.0 זמינים במסך הייבוא וההיסטוריה של גרסה 1.0.

- ציון הזדמנות משקלל 65% ניתוח פונדמנטלי ו-35% ניתוח טכני. הוא דורש כיסוי של 70% ממשקל הרכיבים הפונדמנטליים ו-75% מהרכיבים הטכניים, כולל תמחור ומגמה. כל רכיב מנורמל מתוך המשקל שיש לו ראיות. סף הרשימה להמשך בחינה הוא 65 בשני הציונים (הזדמנות ופונדמנטלי), לצד רווחיות, מאזן, ביטחון בינוני לפחות, תרחישי שווי ל-3–5 שנים, אפסייד בתרחיש הבסיס וממצאים עדכניים למועד הסקירה.
- ציון התאמה לתיק שוקל ענף (25%), משקל ישיר במניה (20%), מטבע מסחר (15%) וסיכון היסטורי (40%). הוא מדמה מניות שלמות במסגרת הפקדה של 4,000 ₪, עם תרחיש התחלתי של 1,000 ₪ שאפשר לשנות. הציון דורש לפחות 80% כיסוי ענפי ומטבעי בהחזקות, חוזה מזוהה, מחיר, שער המרה ונתוני סיכון. חוזה ציבורי ב-IBKR דורש בדיקת הרשאות בחשבון אינטראקטיב ישראל.
- המחקר נעשה מחוץ לאתר. תוכניות הפקדה וסקירות מסלולים ישנות אפשר להמשיך לייבא באמצעות `scripts/save-plan.js` ו-`scripts/save-fund-review.js`.

מחקר מתוזמן ב-Windows יכול להפעיל את `scripts/run-scheduled-research.ps1` באמצעות Codex שמחובר בחשבון ChatGPT. הסקריפט כותב ל-`%LOCALAPPDATA%\Household Economics\Research` ומאמת את הקובץ מול סכמת הייבוא. המחשב צריך להיות פעיל והמשתמש מחובר. קבצי מחקר נכנסים לאתר דרך מסך הייבוא.

להרצה מקומית בגרסת ייצור השתמשו ב-`npm run build` ואז ב-`npm start`, שמחיל את סכמת הנתונים העדכנית. להרצת הבדיקות השתמשו ב-`npm test`.

ב-Windows, אם `prisma db push` נכשל ביצירת בסיס נתונים חדש, צרו קודם קובץ SQLite ריק בנתיב `DATABASE_URL`. עם ההגדרה לדוגמה, הריצו `New-Item -ItemType File -Path prisma/dev.db` ואז הפעילו שוב את הפקודה.
